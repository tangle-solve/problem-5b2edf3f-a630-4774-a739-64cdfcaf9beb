### ALGO-000055: Near-linear oracle complexity in OWF-to-PRG constructions
- **Subfield:** Pseudorandomness, derandomization, and Boolean analysis
- **Open:** Reduce the number of calls to an arbitrary one-way function in a generic PRG construction to \(n^{1+o(1)}\), with explicit security loss and input-length conventions.
- **Status:** This is a separate resource question from seed length. Known generic upper bounds and black-box lower bounds leave a substantial gap.
- **Type:** theory
- **Why:** Oracle-call overhead controls the actual cost of turning a hardness primitive into pseudorandomness.
- **Key works:** Håstad–Impagliazzo–Levin–Luby (1999); Goldreich’s contribution to the 2024 Trevisan memorial problems.
- **Related:** Cryptographic engineering—efficient primitive composition.
